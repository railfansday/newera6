Extract Audio From a Video in the Browser: WAV or WebM Opus, Checked Byte by Byte

📅 03 November 2026 | Sumber: Baca Asli

Pulling the sound out of a video usually means uploading the file to somebody's server. There is a second way: decode the audio track in the tab you already have open, and write the result to your own disk.

I built a small MP4 to test this with - a six second clip with a 440 Hz tone in it - and ran it through the Extract tab of the Audio Studio at app.onepassapps.com/studios/audio. I work on OnePassApps, so this is our tool and our test.

The headline: the file never leaves the tab, and you get a real audio file, not a preview.

The tab is called Extract, and it has three steps. Before you load anything, step 01 reads:

No video yet. Drop one on the stage or browse for it. Up to 32 MiB and 45 minutes.

Step 02 is where the interesting choices live, and they only appear once a video has been checked:

Format, sample rate and channels appear here once the video has been checked.

The page itself sets the boundary - the file hint reads "MP4, MOV, MKV, WebM or MPEG-TS with an audio track · up to 32 MiB and 45 minutes" - and the page line says "Convert, compress, trim and extract audio locally. Your media stays in this browser tab."

There is a note under them: "Defaults keep the source’s mono and sample rate when the chosen encoder supports them." In practice that means the defaults followed my file - a 44.1 kHz mono source came back as 44,100 Hz and Mono without me touching anything.

One line in step 01 tells you what you are about to get, and it matters:

Only the primary audio track is exported. Video and other tracks are discarded locally.

So this is an audio extraction, not a repackage of the whole file.

With probe-extract.mp4 on the stage, the panel showed:

and the stage header confirmed what was inside it before I touched anything:

Pressing Extract audio had produced the file within three seconds and the result panel read:

with Format WAV, Sample rate 44,100 Hz, Channels Mono, Size 519 KiB, and the line that tells you nothing went anywhere else:

Output created locally. Your original file remains unchanged.

The output file name is derived from the source - probe-extract.mp4 became probe-extract-audio.wav.

The plan block on the page reads "Standard is free right now" and "$0 / month" with "No card required", and the run above was done in a tab that was not signed in.

A panel that says "WAV" and a panel that says "MP3" are both just text. So I pulled the actual downloaded blob off the page and parsed it with ffprobe:

That is a genuine RIFF/WAVE file - the first bytes are RIFF then WAVE then fmt - with 16-bit signed little-endian PCM, one channel, at the rate the source had.

The better test is the content. My test video carried a 440 Hz sine tone, so if the extractor really decoded the track, the WAV should contain a 440 Hz waveform. Counting zero crossings over one second of the extracted audio:

880 crossings per second is 440 Hz, exactly the tone I encoded. The audio in the file is the audio from the video.

The format picker is a real dropdown with real choices, so I changed two of them - WebM audio (Opus) and 48,000 Hz - and ran it again. The options list for the rate picker was 48,000 Hz, 44,100 Hz, 32,000 Hz, 24,000 Hz, 16,000 Hz, and the channels list for this mono source held a single entry, Mono.

The second run produced a different file and a different container:

with Format WebM Opus, Sample rate 48,000 Hz, Channels Mono, Size 98.1 KiB.

and the file starts with the four-byte WebM magic 1a 45 df a3. So the picker is not decoration - it changes the container, the codec and the sample rate of the file you download.

Roughly a fifth of the size for the second run. Neither file is smaller than it needs to be - uncompressed WAV is uncompressed WAV - but if you are moving audio over a chat window or attaching it to something, 98 KiB beats 519 KiB, and Opus is the format most players take without asking questions.

The case for doing this in the tab is simple: the file is on your machine already, and you want a smaller file that is still the same audio. A recording you need as a voice note. A clip from a screencast you want to send to someone. A track you want to transcribe.
