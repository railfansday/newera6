How to use Sprite Wanted Posters to dig up and open Sprite Chests in Fortnite Treasure Hunters

📅 03 November 2026 | Sumber: Baca Asli

In Fortnite Treasure Hunters, there are lots of special, seasonal Sprites waiting to be found around the island. One of the first quests you’ll encounter tasks you with using Sprite Wanted Posters to dig up and open Sprite Chests.

The process for acquiring Sprites changes a bit each season, and this task is quite unlike anything we’ve seen before, so it can be a bit tricky to navigate at first. If you’re struggling to get through it, here’s how to use Sprite Wanted Posters to dig up and open Sprite Chests in Fortnite.

You can find Sprite Wanted Posters hanging up on walls anywhere around the Fortnite island. They’re marked with a special symbol and glow color different from the ones used for chests, which makes locating them a bit easier.

Sprite Wanted Posters are marked with a square, poster-shaped icon that has a question mark on it. The glow for these special posters is a softer, slightly lighter gold shade than the one that marks regular chests.

All Wanted Posters are consumables, which means only one player can find and use each one, as they turn into a Sprite Treasure Map you can use as soon as you interact with them. Because of this, they’re more common earlier on in each round.
