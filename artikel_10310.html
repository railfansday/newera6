Some Samsung Galaxy phones are having Android Auto issues with One UI 9

📅 03 November 2026 | Sumber: Baca Asli

Samsung’s Android 17-based One UI 9 update is rolling out more widely and, with it, some apparent issues with Android Auto on some Galaxy phones.

In the time since Samsung’s stable Android 17 update started rolling out, there have been reports popping up around Android Auto issues. Reports of these problems have shown up on Reddit, Samsung’s forums, and Google’s forums.

It’s not a massively widespread problem as far as we can tell, but there’s a clear pattern and enough reports to suggest a trend. Those affected report issues with stuttering performance and/or the connection failing entirely.

The folks at Android Authority found one user test where a Galaxy S25 Edge on One UI 8.5 lacked any issues, but a Galaxy S24 Ultra running One UI 9 immediately reproduced the issues that other users have been reporting. It’s hardly a scientific test, but it shows that One UI 9 is probably responsible for some of this odd behavior.

There’s been no official word on a fix just yet. Let us know in the comments below if you’re dealing with any issues.
