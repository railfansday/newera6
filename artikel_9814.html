How to bulk rename files safely on Windows, macOS and Linux

📅 03 November 2026 | Sumber: Baca Asli

Posted on Nov 3 • Originally published at tidybatch.github.io

Renaming hundreds of files takes seconds. Undoing a bad rename can be impossible. Here is how to do it on Windows, macOS and Linux without losing anything, with the free built-in options first.

Disclosure: this article was written with AI help (Claude), and every command below was run before publishing; the output shown is real. We make TidyBatch, a free command-line tool mentioned at the end, which has a paid Pro version (9 €).

File Explorer. Select the files, press F2, type a name and press Enter. Windows names them Name (1), Name (2), … Fine for quick numbering, but no preview and no patterns.

PowerToys PowerRename (free, from Microsoft). Install Microsoft PowerToys, select files, right-click, Rename with PowerRename. Live preview, regular expressions, numbering and date variables. Ctrl+Z in Explorer undoes the batch right afterwards.

Rename-Item refuses to replace an existing file (Rename-Item: The file '…/a_b.jpg' already exists.). Good, but in a long batch a few files fail halfway through, so read the red errors.

Finder. Select the files, right-click, Rename…. Replace Text, Add Text or Format with a counter, with an example of the result. Edit → Undo straight away if it is wrong.

Terminal. Use mv -n (no-clobber) and print the commands before you run them:

There are two different rename commands (Perl and util-linux) with different syntax. Run rename --version to see which you have. The util-linux one only prints the plan with -v:

Say you renumber 1.txt, 2.txt, 3.txt to 2.txt, 3.txt, 4.txt. A simple loop renames 1.txt → 2.txt first. On Linux and macOS a plain mv or Python's os.rename overwrites the original 2.txt without warning. On Windows it fails instead, leaving the folder half renamed.

The fix is two phases: move every file to a temporary name, then to its final name. Or rename into a new, empty folder. A related trap: on Windows and macOS Photo.JPG and photo.jpg are the same file, so collision checks must ignore case.

TidyBatch is a free, open-source command-line tool (we made it) built around these rules. It previews by default, renames in two phases, checks collisions without case, and keeps a journal so you can undo with one command, even after an interrupted run. If you only use Windows and like clicking, PowerRename is excellent and free. TidyBatch is for when you want the same command on every OS, in scripts, with an undo that survives closing the window.
