2D pixel action game RGB: Execution to be published by Top Hat Studios

📅 03 November 2026 | Sumber: Baca Asli

Top Hat Studios will publish Purechito-developed 2D pixel action game RGB: Execution when it launches for PC via Steam, the companies announced. A release date was not announced.

Here is an overview of the game, via its Steam page:

On September 9, 2012, an Altair unit is manually reactivated by an unknown entity. 7,305 days have passed since its last record. The state of the world is unknown. Your task remains unchanged: return to the ocean, and kill Vega.

RGB: Execution is a 2D pixel action game focused mostly on boss encounters, a tactical boss-rush. Heavily narrative-driven, inspired by “unique bosses” experiences such as Shadow of the Colossus. Each boss is a self-contained challenge, demanding a different commitment from the player—both mechanically and mentally—to uncover how it can be defeated.
