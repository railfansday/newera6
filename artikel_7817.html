4 Common Tools With a Hidden Second Function Most People Never Use

📅 03 November 2026 | Sumber: Baca Asli

Some everyday tools hide useful features in plain sight. These four have built-in cutters, openers, and other functions worth knowing about.

A pair of pliers can sit in the same toolbox for years without its owner ever noticing the cutting edge near the hinge. The same goes for measuring tools, utility knives, and even gadgets in a kitchen drawer.

Some everyday tools have other tools built in, but those extra features are easy to overlook. Anyone who has spent time on home improvement projects knows how frustrating it can be to search for a tool, especially when the one already in hand could do the job.

Of course, features vary by model, but these four familiar tools have some useful extras worth knowing about.

Some pliers have built-in wire cutters near the hinge, just behind the gripping jaws. These can trim soft wire without needing a separate pair of cutters. Not every pair has this feature, though. It’s also worth checking whether the tool has wire strippers, which remove insulation without cutting through the wire itself.

Some wire strippers have small, threaded holes near the handles that allow users to shorten machine screws. The screw goes into the appropriately sized hole, and squeezing the handles cuts it to length. This feature can come in handy when installing electrical fixtures or other hardware that requires shorter screws.

Some manual can openers have a bottle opener built into the handle or near the cutting mechanism. Depending on the design, it may look like a small notch or hook in the metal. Other models have magnets that help lift cut lids from cans without touching the sharp edges.

Many nail clippers have a small metal file that folds out from beneath the lever or sits along the body. It helps smooth rough edges after trimming. Some models also have a pointed tip for cleaning beneath nails, although the design and placement of these extra features vary.
