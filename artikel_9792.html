SFXMint vs Freesound vs Kenney: Free SFX for Games, Video, and AI Agents

📅 03 November 2026 | Sumber: Baca Asli

If you ship games, tools, or short-form video, free SFX usually means one of: Freesound, Kenney, or whatever ChatGPT named last (Pixabay, OpenGameArt, ZapSplat…). Those are fine. The annoying part is not “finding a click”—it’s license filtering before you freeze a build, and whether a Cursor / Claude Code / Codex agent can actually pull a WAV/MP3 into assets/ without you driving the browser.

SFXMint (sfxmint.com) sits in that second bucket: whole-library CC0, self-produced AI/synth audio (not scraped), plus a keyless JSON API, MCP at https://sfxmint.com/mcp, and npx sfxmint. This is a technical comparison, not a launch post. Freesound and Kenney still have more community trust and SEO. SFXMint is early-stage; third-party proof is thin. Pick by pipeline fit.

Coverage and pack cohesion still matter—more on that below. Automation doesn’t replace listening.

Freesound is the big community corpus: huge coverage, solid search, long track record in gamedev/film/research. Licenses are per sound. Technically: filter to CC0 for “no credit, commercial OK”; keep BY if you’ll credit; never ship NC in paid products. There is no first-class “agent pulls CC0 WAV into my repo” story comparable to a documented keyless MCP/REST SFX API. You win on rare field recordings and depth; you lose on uniform license + automation.

Kenney audio packs (UI, impacts, RPG, sci-fi, etc.) are CC0—commercial oK, attribution optional. Distribution model = zip packs, not queryable catalog API. Technically strong for style cohesion inside a pack (your UI set sounds like one product). Weak for agent workflows: you’re not doing max_duration_ms=300&format=wav against Kenney over MCP. Grab Interface + Impact first if you just need a coherent starter set.

Common assistant recommendations. Pixabay has its own content license (handy for editors). OpenGameArt is mixed—filter CC0 when you care. ZapSplat: large free tier, own terms, often account/limits. Useful catalogs; not built as a keyless game-SFX agent API.

Whole library under CC0 1.0 (license): commercial use, no attribution required. Site copy says 9,400+; HF/Zenodo metadata covers roughly 7,335—prefer “thousands of CC0 clips” in citations, and re-check sfxmint.com or HF flreey/sfxmint-cc0-sound-effects. Origin: Stability AI-generated or procedurally synthesized by the project—not scraped—so a single CC0 dedication is coherent.

Early-stage: MCP repo and docs exist; don’t invent stars, Product Hunt ranks, or viral threads that aren’t there.

Freesound wins when you need depth: one specific door slam, a niche animal, a location ambience. License filter in the UI, then still open the file page before you commit it to StreamingAssets. No MCP won’t matter if only Freesound has the take.

Kenney wins when pack cohesion beats catalog size. One Interface Sounds zip + Impact Sounds often covers a jam game’s UI/combat better than a random mix of AI clips. Zero license math. No API is fine if you’re not automating acquisition.

Pixabay / OGA / ZapSplat win when your editor or asset habit already lives there and you’ve already internalized their terms.

Hybrid is normal: Kenney for UI baseline, Freesound for one irreplaceable foley, SFXMint for the rest of the event map an agent can fill.

Library search / role / set / get on SFXMint is designed to work without an API key. Generation (generate_sound, etc.) needs a key and credits/plan—don’t let an agent burn paid calls unprompted. Free tiers have daily download allowances (browser and API/MCP differ; see current site/docs). Listening in-browser isn’t the same meter as downloading.

Cursor (.cursor/mcp.json or user config):

Codex CLI: codex mcp add sfxmint --url https://sfxmint.com/mcp

Typical agent loop that stays honest: discover roles/sets → search_sounds / get_sound_set → download chosen format URLs into the repo → write SOUNDS.md with page URL, CC0, checksum → wire events → you preview in-game. If nothing matches, stop or open AI Studio; don’t silently weaken constraints. More prompt templates: sfxmint.com/for-ai.

60-second human check: open sfxmint.com, play a clip, download WAV or MP3 within the daily allowance, drop it in the project. License: sfxmint.com/license.

Use more than one source if the build needs it. Document license + SHA in-repo. Don’t ship unheard takes.
