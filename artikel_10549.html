Public Discord messages might start showing up in Google Search, unless users opt out

📅 03 November 2026 | Sumber: Baca Asli

Discord announced today that Discoverable Server web pages will begin showing summaries and pulled content, which might show up in search engines.

Discord splits its servers into three different types: private, community, and discoverable. The latter is the most public version. No one needs an invite, and anyone can message, given that the admins of that server haven’t blocked you completely.

In a recent press release, Discord notes that all Discoverable Servers will get a Server Web Page. The page is essentially an overall summary of that server, so users can easily gauge whether they its something they want to join.

Discord says that discussion summaries will also appear on those server web pages, extracted from public channels. Any conversation that might be deemed noteworthy, whether by an AI model or moderator, could appear on that web page, and by extension, search engines like Google.

It sounds like Discord is hoping channels surface in Google’s AI Mode or other engines, like Reddit, when users search for certain topics. It’s not a bad idea, as message boards often contain answers to incredibly niche questions otherwise hard to find on the internet.

The release makes it clear that server admins can exclude certain channels and channel summaries, but doesn’t say the entire server can opt out. That seems to only be possible by switching server types.

Individual users can also opt out. Users can head to User Settings > Data and Privacy to control whether their public messages appear in the server web page.

Discord says these changes will take effect starting November 16. Admins and users wishing to opt out of having their public messages and channels included in web pages, and by extension, search results, will need to opt out before then.
